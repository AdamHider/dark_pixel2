## 1. Что это и как запустить

Это чисто клиентское приложение на ванильном JavaScript без сборки и зависимостей: набор
`<script>`-ов в HTML. Оно генерирует процедурную карту мира (рельеф, климат, реки, регионы,
ресурсы, поселения, дороги) и рисует её пиксель-артом на `<canvas>`.

Запуск: достаточно открыть `index.html` в браузере (файл открывается с диска, сервер не нужен).
`sprite-demo.html` — отдельный редактор спрайтов объектов.

Порядок подключения скриптов важен (каждый следующий использует предыдущие):

```
map-generator.js  →  seasons.js  →  map-painter.js
                                   →  sprite-renderer.js  (использует функции цвета из map-painter.js)
                                   →  sprite-examples.js
map-renderer.js   (использует MapPainter и SpriteRenderer)
main.js           (использует всё вместе)
```

## 2. Архитектура: слои и поток данных

Проект делится на **логику** (что за мир) и **отрисовку** (как он выглядит). Это главный принцип.

```
                    ┌──────────────────────────────┐
                    │  MapGenerator (логика мира)  │
                    │  terrain, biome, river,      │
                    │  regionId, resource, roads…  │
                    └───────────────┬──────────────┘
                                    │ плоские массивы (одна клетка — один индекс)
                                    ▼
   ┌─────────────────────────┐   ┌───────────────────────────────┐
   │  MapPainter (картинка)  │   │  MapRenderer (камера и ввод)  │
   │  один большой холст 1:1  │──▶│  показывает кусок холста       │
   │  buffer                 │   │  + выделение, + объекты        │
   └─────────────────────────┘   └───────────────┬───────────────┘
                                                  │
                                                  ▼
                                   ┌──────────────────────────────┐
                                   │  SpriteRenderer (объекты)     │
                                   │  армии, города — поверх карты │
                                   └──────────────────────────────┘
```

Ключевые решения производительности:

* **Карта хранится в плоских типизированных массивах.** Клетка `(x, y)` — это индекс
  `y * size + x`. Один и тот же индекс используется во всех слоях (`elevation[i]`, `biome[i]` и т. д.).
* **Карта рисуется один раз** в скрытый холст `buffer` в масштабе 1:1 (пиксель карты = пиксель
  холста). Движение и зум — это просто показ нужного куска `buffer` через `drawImage`.
* **Горячие циклы работают с `Int32Array`** цветов и целочисленной арифметикой, чтобы не
  создавать объекты в циклах на миллионы итераций.

## 3. Общие соглашения

* **Клетка (tile)** — квадрат `tileSize × tileSize` пикселей (по умолчанию 16).
* **Пиксель карты** — координаты в большом холсте `map.size * tileSize`.
* **`px(n)`** — переводит «пиксели для клетки 12×12» (базовый размер, под который нарисованы все
  пропорции) в текущий размер клетки: `round(n * tileSize / 12)`. Поэтому `tileSize` можно менять.
* **Списки-словари** (`Terrain`, `Biome`, `Shore`, `Resource`) — замороженные объекты-перечисления.
* **«8 соседей»** — включая диагонали; **«4 соседа»** — только по сторонам.
* **Сезон** — `spring | summer | autumn | winter`; задаёт палитру и «сдвиг температуры».

## 4. map-generator.js — логика мира

### 4.1 Справочники

| Имя | Значения |
|-----|----------|
| `Terrain` | `DEEP_WATER 0`, `SHALLOW_WATER 1`, `PLAIN 2`, `MOUNTAIN 3` |
| `Biome` | `TUNDRA 0`, `TAIGA 1`, `GRASSLAND 2`, `STEPPE 3`, `DESERT 4`, `SAVANNA 5` |
| `Shore` | `NONE 0`, `BEACH 1`, `ROCKY 2`, `CLIFF 3` |
| `Resource` | `NONE 0`, `WOOD 1`, `WHEAT 2`, `GOLD 3`, `ETHER 4`, `IRON 5`, `SETTLEMENT 6` |
| `ResourceInfo` | что даёт ресурс (числа условные, под экономику игры) |
| `ROAD_DIRECTIONS` | 8 направлений дороги; индекс `d` и `7 - d` — противоположные |

### 4.2 Вспомогательные функции (уровень файла)

| Функция | Назначение |
|---------|-----------|
| `clamp(value, min = 0, max = 1)` | ограничение значения в диапазон |
| `hash32(n)` | хорошо перемешанный хеш числа в `0..2^32`. Нужен, чтобы соседние номера клеток давали несвязанные значения (простое умножение давало «решётчатые» узоры у рек). |
| `lerp(a, b, t)` | линейная интерполяция |
| `createRandom(seed)` | ГПСЧ mulberry32. Один seed → одна и та же последовательность. |
| `rankNormalize(values)` | выравнивает значения до равномерных `0..1` по рангу (минимум → 0, максимум → 1). Благодаря этому порог `0.4` честно означает «нижние 40 %». |
| `percentile(values, share)` | значение на заданной доле отсортированного списка (`0.5` — медиана) |

### 4.3 class ValueNoise — плавный шум

Даёт значения `0..1`, где соседние точки похожи. На этом строится почти вся генерация.

| Метод | Назначение |
|-------|-----------|
| `constructor(seed)` | строит решётку `65×65` случайных значений |
| `latticeValue(ix, iy)` | значение узла решётки с заворотом (`& 63`) |
| `sample(x, y)` | одна октава: интерполяция между четырьмя ближайшими узлами (сглаживание `t²(3−2t)`) |
| `fractal(x, y, octaves)` | несколько октав (крупные формы + мелкие детали) |

### 4.4 class MapGenerator — генератор карты

Хранит карту в плоских массивах. Основные публичные поля после `generate()`:

* рельеф и вода: `elevation`, `seaLevel`, `terrain`, `waterDepth`, `ridge`, `massif`, `mountainHeight`
* климат: `temperature`, `moisture`, `biome`, `shore`
* реки: `river` (0..3), `riverTo`, `riverFlow`, `filled`, `flowTo`, `crossing`
* ресурсы: `resource`, `population`
* регионы: `regionId`, `regionSizes`, `regionPopulation`, `landTiles`
* поселения и дороги: `settlements`, `settlementGroups`, `settlementGroup`, `roadLevel`, `roadLinks`

**`MapGenerator.DEFAULTS`** — полный список параметров (250+ строк комментариев). Разделы:
суша/вода, климат, ресурсы, редкие ресурсы, берега, поселения, дороги, реки/озёра, регионы.
Все параметры можно переопределить в конструкторе (см. `main.js`).

### 4.5 Типовые методы MapGenerator

#### Главный конвейер

| Метод | Что делает |
|-------|-----------|
| `generate(seed)` | запускает весь конвейер по порядку (см. ниже) и возвращает `this` |
| `createNoiseLayers()` | создаёт набор `ValueNoise` для всех нужд (высота, хребты, влага, деформация, лес, руда и т. д.) |
| `allocateLayers()` | выделяет все типизированные массивы под размер карты |

Порядок в `generate()` — это и есть «карта зависимостей»:

```
высота → острова → влага → рельеф/вода → горы → острова(малые) → вода(глубина)
→ температура → биомы → ресурсы → реки → берега → редкие ресурсы → переправы
→ регионы → поселения → дороги
```

#### Вспомогательные методы клеток

| Метод | Назначение |
|-------|-----------|
| `index(x, y)` | `y * size + x` |
| `neighbors(i)` | 4 соседа по сторонам внутри карты |
| `neighbors8(i)` | 8 соседей, включая диагонали |
| `isLand(i)` | `terrain[i] >= PLAIN` |

#### 1. Высота и вода

| Метод | Назначение |
|-------|-----------|
| `generateElevation()` | шум + спад к краям (мир окружён водой) + хребты + деформация координат (warp) для извилистых берегов |
| `scatterIslands()` | в полосе мелководья отдельные «горбы» шума поднимает над уровнем моря |
| `generateMoisture()` | влага = шум, выровненный `rankNormalize` |
| `classifyTerrain()` | пороги по долям (`waterShare`, `mountainShare`), высота горы растёт с «хребтовостью» и «массивностью» |
| `removeSmallMountains()` | горы меньше `minMountainSize` → равнина |
| `removeSmallIslands()` | клочки суши меньше `minIslandSize` → вода |
| `collectLandComponent(start, visited)` | обход в ширину: все клетки суши, связанные с `start` |
| `collectLandTiles()` | пересобирает список `landTiles` |
| `computeWaterDepth()` | расстояние до ближайшей суши (ВОЛНА от суши); мелководье — узкая полоса |
| `fillDepressions()` | priority-flood: у каждой клетки появляется сток к морю; впадины становятся озёрами (`lakeDepth`, `lakeMinSize`) |

#### 2. Климат и биомы

| Метод | Назначение |
|-------|-----------|
| `generateTemperature()` | «север холодно, юг жарко» + шум − охлаждение от высоты |
| `assignBiomes()` | для равнин выбирает биом по температуре и влаге |
| `pickBiome(t, m)` | таблица переходов биомов по поясам (холодный, умеренный, жаркий) |

#### 3. Ресурсы

| Метод | Назначение |
|-------|-----------|
| `placeResources()` | лес (`forest*`) и поля (`wheat*`) с проверкой климата |
| `createPatchLayer(...)` | «пятна»: крупные скопления + мелкие разбросанные кучки |
| `createDensityLayer(noise, scale)` | слой плавного шума, выровненный до `0..1` |
| `placeRareResources()` | вызывает `placeGold`, `placeIron`, `placeEther` |
| `placeGold()` / `placeIron()` | в горах и предгорьях скоплениями (железо чаще, золото не вытесняет) |
| `tilesNearMountains(distance)` | 1 для гор и суши не дальше `distance` клеток от гор |
| `placeEther()` / `createFaultLayer()` | «линии разлома» — где шум близок к 0.5 |
| `classifyShores()` | тип берега: горы у воды → утёсы; низкие тёплые → пляжи; прочее → камни |

#### 4. Реки

| Метод | Назначение |
|-------|-----------|
| `isDiagonal(a, b)` | шаг по диагонали между клетками |
| `generateRivers()` | дождь на каждую клетку → сток по `flowTo` → пороги `riverThresholds` → ширина реки |
| `placeRiverCrossings()` | на прямых участках изредка брод или мост |

#### 5. Регионы

| Метод | Назначение |
|-------|-----------|
| `buildRegions()` | весь конвейер регионов (см. подробнее ниже) |
| `shuffled(list)` | копия списка в случайном порядке (Фишер–Йетс) |
| `buildRegionCosts()` | цена «зайти» в клетку: единица + шум + горы-преграда |
| `regionNeighbors(i)` | соседи для роста региона (диагональ только если обе клетки «за углом» годятся) |
| `regionAreas()` | отдельные массивы региональной суши (без рек и воды) |
| `pickRegionSeeds(area, count)` | семена с зазором; равнинам предпочтение |
| `markBlocked(blocked, i, radius)` | помечает окрестность радиуса как занятую |
| `assignRegions(seeds)` | Дейкстра от всех семян сразу: клетка достаётся тому, до кого «дешевле» |
| `relaxRegionSeeds(seeds)` | релаксация Ллойда: новое семя — ближайшее к центру тяжести |
| `repairRegionConnectivity()` | отрезанные обрывки региона отдаёт соседу с самой длинной границей |
| `bestNeighborRegion(tiles, ownId)` | сосед с самой длинной общей границей |
| `countRegionSizes()` | пересчитывает `regionSizes` |
| `mergeSmallRegions()` | региона меньше `regionMergeBelow` вливает в соседа (или через реку) |
| `regionAcrossRiver(tiles, ownId)` | клочок за рекой присоединяет к региону на другом берегу |
| `regionContacts(tile, id)` | сколько из 8 соседей принадлежит региону `id` |
| `balanceRegionSizes()` | граничные клетки перетекают от больших регионов к маленьким |
| `smoothRegionBorders(min, max)` | сглаживает границы: клетка уходит к региону большинства соседей |
| `staysConnectedWithout(removed, id)` | не расколется ли регион, если убрать клетку |
| `renumberRegions()` | номера регионов подряд, без дыр |

`buildRegions()` по шагам: (1) семена по площади каждого массива суши; (2) деление земли
Дейкстрой; (3) несколько проходов релаксации; (4) починка связности, слияние мелочи,
выравнивание размеров и сглаживание границ.

#### 6. Поселения и дороги

| Метод | Назначение |
|-------|-----------|
| `placeSettlements()` | население региона из «обитаемости» + случайный множитель; группы из 1–4 клеток |
| `settlementLevelFor(pop)` | уровень клетки 1..4 по населению (логарифмическая шкала) |
| `isSettlementSite(...)` | подходит ли клетка под поселение |
| `growSettlementGroup(...)` | лучшая клетка региона + наращивание соседними |
| `commitSettlementGroup(...)` | запись группы: делёж населения, уровни, дорожки между клетками |
| `computeHabitability()` | годность клетки для жизни: биом × влага + поправки (река, берег, утёс) |
| `buildRoads()` | K ближайших соседей каждого поселения → каркас (как остовное дерево) + петли; путь A* |
| `findRoadPath(start, goal)` | A* с кэшем поиска (`searchCost`, `searchStamp`, `searchFrom`) |
| `roadStepCost(...)` | цена шага: вода/горы непроходимы, мост дорог, чужие дороги дёшевы |
| `carveRoad(path)` | сохраняет путь: `roadLevel`, `roadLinks` (биты направлений), переправы |

#### Сводки для интерфейса

| Метод | Назначение |
|-------|-----------|
| `getRegionInfo(regionId)` | сводка по региону: размер, горы, реки, население, ресурсы, биомы |
| `getTileInfo(x, y)` | сводка по клетке (используется для наведения и выделения) |

### 4.6 class MinHeap — очередь с приоритетом

| `push(cost, tile, region)` | добавить элемент |

| `get size` | число элементов |

## 6. map-painter.js — пиксельная отрисовка

Это самый большой файл. `MapPainter` рисует **карту целиком в один холст, пиксель за пикселем**.
Слои снизу вверх: фон → рельеф гор → реки → текстура → границы регионов → декорации.

### 6.1 Функции и данные уровня файла

| Имя | Назначение |
|-----|-----------|
| `COLORS` | цвета, не зависящие от сезона (мосты, камень, золото, эфир, дома, кости…) |
| `packRgb(r, g, b)` | цвет в одно 32-битное число (как в `Int32Array`) |
| `hexToPacked(hex)` | `#rrggbb` → число |
| `WHITE`, `BLACK` | готовые цвета |
| `hslToPacked(h, s, l)` | HSL → число (для видов «температура» и «регионы») |
| `mixPacked(a, b, t)` | смесь двух цветов, целочисленно (вызывается миллионы раз) |
| `speckColor(color, lighter)` | крапинка чуть светлее/темнее |
| `shadeFast(color, amount)` | осветлить/затемнить, целочисленно |
| `shadePacked(color, amount)` | то же через `mixPacked` |
| `MOUNTAIN_RAMP` | палитра скал от холодной тени к тёплому свету |
| `packPalette(palette)` | палитра сезона в числах |
| `SNOW_TEMPERATURE`, `ICE_TEMPERATURE`, `RIVER_ICE_TEMPERATURE` | пороги снега и льда |
| `WATER_DEPTH_STEPS`, `waterShadeIndex(depth)` | оттенок воды по глубине |
| `STEP_AMOUNTS`, `BAYER` | ступени светотени и матрица упорядоченного дизеринга 4×4 |
| `tileHash(x, y, k)`, `hashUnit(...)` | детерминированные «случайности» (не меняются при перерисовке) |
| `smoothstep(t)` | плавная интерполяция |

### 6.2 class LatticeNoise

Плавный шум с ячейкой `cell` пикселей: решётка и сглаженные позиции считаются один раз.

| Метод | Назначение |
|-------|-----------|
| `constructor(width, cell, salt)` | строит решётку и таблицы индексов/долей |
| `at(gx, gy)` | значение `0..1` в пикселе |

### 6.3 Свободные функции-помощники

| Функция | Назначение |
|---------|-----------|
| `computeHillShading({...})` | один раз считает список пикселей светотени холмов (индекс + «код» ступени/оврага) |
| `applyHillShading(pixels, {index, code, count})` | при перерисовке только применяет список |

### 6.4 class PixelBuffer

Маленький пиксельный буфер для рисунков (дома, руды, эфир): прозрачный фон, фигуры, контур.

| Метод | Назначение |
|-------|-----------|
| `put(x, y, color)` / `rect(...)` | запись пикселя / прямоугольника |
| `ellipse(cx, cy, rx, ry, base, light, dark)` | эллипс с объёмом (свет слева-сверху) |
| `outline(color)` | контур: прозрачные пиксели, у которых есть закрашенный сосед |

### 6.5 class MapPainter

#### Главный метод и вспомогательные

| Метод | Назначение |
|-------|-----------|
| `constructor(map, options)` | настройки рисования (см. ниже) |
| `paint({view, seasonName, showBorders, mood})` | рисует всю карту и возвращает холст. Слои можно отключать через `options.layers` |
| `px(n)` | «пиксели клетки 12×12» → текущие |
| `forEachTile(callback)` | обход всех клеток |
| `seasonalTemperature(i)` | температура с учётом сезона |
| `put` / `blend` / `rect` / `linePoints` | базовые операции рисования (Брезенхэм для отрезков) |

`paint()` по шагам: `paintBase` → `smoothCoast` → (если вид «рельеф») `buildReliefHeights`,
`paintHills`, `paintShores`, `paintRivers`, `paintRoads`, `paintSettlementGround` →
`paintTexture` → `paintRegionBorders` → `paintScene` → `applyGrading` → источники света.

#### Фон и цвет клетки

| Метод | Назначение |
|-------|-----------|
| `paintBase()` | цвет каждой клетки смешивается с соседями дизерингом (билинейные веса, но выбор из 4 цветов) |
| `blendGrid()` | заранее считает квадранты и доли пикселей в клетке |
| `blendChoices(tx, ty)` | три таблицы выбора (мягкая, береговая, «ближайший сосед») |
| `buildAxisTables()` | для каждой оси: между какими клетками лежит пиксель и насколько |
| `isUniform(colors, tx, ty, color)` | клетка и все 8 соседей одного цвета (быстрый путь заливки) |
| `smoothCoast()` | мажоритарный фильтр по маске воды — скругляет ступенчатый берег |
| `buildTileColors()` | цвет и признак «вода» для каждой клетки |
| `isRiverTileInRegionsView(i)` | в виде «регионы» клетки рек показываем как воду |
| `tileColor(i)` | цвет клетки в зависимости от вида |
| `waterColor(i)`, `groundColor(i)` | цвет воды (с учётом глубины и льда) и земли (с поправкой на плодородие и снег) |
| `snowCoverage(i)` | доля снега: 0, 1/3, 2/3 или 1 |
| `nearRiver(i)` | клетка рядом с рекой (кэш на карту) |
| `fertilityTint(i, color)` | оттенок внутри биома по плодородию |
| `shadeStep(color, step)` | цвет ± ступень светотени |

#### Холмы, берега, рельеф гор

| Метод | Назначение |
|-------|-----------|
| `paintHills()` | светотень холмов + овраги в сухих местах |
| `buildHillHeights()` | карта холмов (шум + крупный рельеф суши), кэшируется |
| `paintShores()` | тип берега: пляж / галька / утёс + пена у воды |
| `paintCliffs(queue, distance, kind)` | утёсы: стенка под южным краем суши и тень на воде |
| `buildReliefHeights()` | карта высот гор: мультифрактал (ветвящиеся хребты), warp, размытие |
| `blurHeights(height, zone, radius)` | размытие карты высот (по строкам, потом по столбцам) |
| `prepareReliefRows()` | готовит данные для построчной отрисовки гор |
| `paintReliefRow(relief, gy)` | одна строка карты высот → экран (наклонная проекция: выше → севернее) |
| `fillColumn(gx, fromY, toY, color)` | закраска «склона» под поднятым пикселем |
| `blurMountainHeights()` | двойное размытие высот клеток, чтобы горы «набухали» |
| `mountainFootprint()` | 1 — клетка горы, 0 — остальное |
| `tilesNearRelief(blurred)` | клетки, где может быть рельеф (горы и рядом) |
| `snowLevel(tile)` | с какой относительной высоты лежит снег |

#### Реки

| Метод | Назначение |
|-------|-----------|
| `paintRivers()` | красит маску реки, кромку, берег |
| `buildRiverGeometry()` | маска реки, кромка с расстоянием до края, «сердцевина»; кэшируется |
| `riverWidthAt(i)`, `riverWidth(level)`, `band(thickness)` | ширина реки по количеству воды |
| `paintBankPixel(xx, yy, k, outside, bankColors)` | берег реки (мокрый пиксель + редкая галька/песок) |

#### Текстура и стиль

| Метод | Назначение |
|-------|-----------|
| `paintTexture()` | крапинки, волны у воды, детали лугов и пучки травы |
| `speckLayout(speckCount)` | расположение крапинок (кэш на карту) |
| `paintGroundDetail(x, y, i)` | сезонные мелочи (цветы весной, листва осенью) |
| `paintTufts(x, y, i)` | пучки травы (густота зависит от влаги и биома) |
| `putGround(x, y, color)` | пиксель земли (не поверх воды и рек) |
| `moodize(color)` | приглушение цвета в тёмном стиле |
| `applyGrading()` | цветокоррекция, туман, виньетка |
| `buildFog()` | густота тумана (кэш на карту) |
| `drawLight(x, y, color, glowColor, glowRadius)` | источник света с мягким свечением |

#### Мрачные детали (только тёмный стиль)

| Метод | Назначение |
|-------|-----------|
| `collectProps(items)` | кости, вороны, развалины, виселицы |
| `drawBones` / `drawCrow` / `drawRuin` / `drawGibbet` | рисунки этих деталей |

#### Дороги и поселения

| Метод | Назначение |
|-------|-----------|
| `roadWidth(level)` | ширина дороги по её уровню |
| `paintRoads()` | рисует полосу утоптанной земли и саму дорогу |
| `buildRoadGeometry()` | пиксели дорог (кэш на карту) |
| `settlementLayout(x, y, i)` | раскладка домов клетки (кэш) |
| `layoutSettlement(x, y, i)` | **основная** раскладка: сколько и где домиков, улица, пятна земли |
| `paintSettlementGround()` | утоптанная земля и улица на карте |
| `settlementGround(layout)` | пиксели земли поселения (кэш) |
| `collectSettlement(items, x, y, i)` | добавляет дома в список декораций |
| `houseColor(color)` | приглушение цвета построек |
| `houseSprite(part, roll, snow)` | рисунок здания (кэш) |
| `drawHouse(...)`, `drawBuildingShadow(...)`, `blitSprite(...)` | отрисовка дома и тени |

#### Руды, эфир, границы, контуры, сетка, декорации

| Метод | Назначение |
|-------|-----------|
| `oreSprite(kind, variant)`, `drawOreTile(x, y, kind)` | золото и железо |
| `etherSprite(variant)`, `drawEther(x, y)` | кристаллы и грибы эфира |
| `buildPixelRegions()` | чей пиксель: номер региона для каждого пикселя |
| `smoothPixelRegions(owner)` | скругление границ регионов мажоритарным фильтром |
| `paintRegionBorders()` | тонкая линия по границам регионов |
| `traceOutline(inside, ...)` | контур области пикселей (замкнутые ломаные), сглаживание срезанием углов Чайкина |
| `regionOutline(regionId, smoothing)` | контур региона для выделения |
| `buildCellMap()`, `cellAt(worldX, worldY)`, `cellOutline(tile, ...)` | карта ячеек: на какую клетку «работает» пиксель; форма ячейки |
| `paintGrid()` | отдельный слой сетки клеток |
| `paintScene()` | горы и декорации вместе, строка за строкой (правильный порядок перекрытия) |
| `collectDecorations()` | список декораций, отсортированный по «основанию» |
| `collectTrees(items, x, y, i)` | 2–3 дерева на клетку (ели или лиственные) |
| `drawShadow`, `drawBroadleaf`, `drawBareTree`, `drawConifer`, `drawWheat` | рисунки деревьев и пшеницы |
| `liftAtTile(x, y)` | насколько поднята поверхность гор в центре клетки |
| `paintCrossing(x, y, i)`, `crossingDirections(x, y, i)` | мост или брод и их направление |

#### Настройки рисования (`options` MapPainter)

Важнейшие: `tileSize`, `blendSharpness`, `coastSharpness`, `peakSharpness`, `mountainLift`,

## 7. sprite-renderer.js — объекты по конфигу

`SpriteRenderer` рисует объекты (города, деревни, армии, башни) **по описанию-конфигу**, без
готовых картинок. Подключать после `map-painter.js` (оттуда берутся функции цвета).

### 7.1 Формат конфига (кратко)

```js
{
  id, size: [w, h], anchor: [x, y],
  palette: { wall: '#c8b48a', roof: { shade: 'wall', amount: -0.4 }, flag: '$team' },
  shadow: { rx, ry, alpha }, outline: '#241810', light: 'nw' | 'ne',
  layers: [ ...фигуры... ],
  variants: { winter: { palette, layers, addLayers } }
}
```

Фигуры: `rect`, `ellipse`, `polygon`, `line`, `pixels` (графика буквами), `scatter`,
`gradient`. Общие поля: `fill`, `bevel`, `alpha`, `when`, `repeat`.

Вызов: `render(config, { season, colors, frame, flags, scale, flipX })` →
`{ canvas, width, height, anchorX, anchorY, scale }`. Результат кэшируется.

### 7.2 Типовые методы

| Метод | Назначение |
|-------|-----------|
| `render(config, options)` | главный: применяет вариант, рисует слои, контур, тень; кэширует |
| `resolveConfig(config, options)` | сезонный вариант: палитра дополняет, `layers` заменяют, `addLayers` дополняют |
| `isActive(layer, options, frame)` | проверка `when` (сезон, кадр, флаг) |
| `repeatOffsets(repeat)` | смещения для повторов (список или сетка) |
| `color(spec, context, depth)` | разбор цвета: `#hex`, `$имя`, имя из палитры, `{shade}`, `{mix}` |
| `drawLayer(context, layer, dx, dy)` | рисует одну фигуру (кроме pixels/scatter/gradient) |
| `rasterize(context, layer, dx, dy)` | фигура → маска (1 — пиксель принадлежит фигуре) |
| `insidePolygon(x, y, points)` | чётно-нечётный тест точки внутри многоугольника |
| `linePoints(x0, y0, x1, y1)` | пиксели отрезка (Брезенхэм) |
| `drawPixels(context, layer, dx, dy)` | точечная графика буквами |
| `drawScatter(context, layer, dx, dy)` | «россыпь» случайных точек (детерминированно) |
| `drawGradient(context, layer, dx, dy)` | ступенчатый градиент |
| `drawShadow(context, shadow, anchor)` | овальная тень под основанием |
| `drawOutline(context, spec)` | контур вокруг силуэта |
| `setPixel(context, x, y, color, alpha)` | запись пикселя со смешиванием |
| `toCanvas(context, options, anchor)` | буфер → `<canvas>` с учётом масштаба и `flipX` |

## 9. map-renderer.js — камера и взаимодействие

`MapRenderer` = камера + управление. Карту рисует `MapPainter` один раз в `buffer` 1:1, а
рендерер лишь показывает нужный кусок с нужным зумом.

### 9.1 Публичные методы

| Метод | Назначение |
|-------|-----------|
| `constructor(canvas, map, options)` | настройки (см. ниже), привязка событий, `ResizeObserver` |
| `refresh()` | после новой генерации: сброс выделения, перерисовка буфера, `fitToView` |
| `setView(view)` | вид: `terrain` / `temperature` / `regions` |
| `setSeason(name)` | сезон |
| `setMood(mood)` | `dark` / `light` |
| `setShowSettlements(show)`, `setShowBorders(show)` | показ поселений и границ |
| `setShowGrid(show)` | сетка (отдельный слой, карту не перерисовывает) |
| `setObjects(list)` / `addObject` / `removeObject` | объекты на карте |

### 9.2 Объекты и камера

| Метод | Назначение |
|-------|-----------|
| `objectBox(object)` | экранный прямоугольник объекта (левый верх и размер спрайта) |
| `drawObjects()` | рисует объекты снизу вверх (южнее — позже, перекрывает) |
| `objectAt(point)` | объект под точкой (самый южный из перекрывающихся) |
| `get worldSize` | размер мира в пикселях |
| `fitToView()` | показать всю карту |
| `centerOn(worldX, worldY)` | центрировать на точке мира |
| `clampCamera()` | не дать камере улететь (за краем видно не больше половины экрана) |
| `panBy(dx, dy)` | сдвиг камеры |
| `zoomAt(screenX, screenY, factor)` | зум так, чтобы точка под курсором осталась на месте |
| `screenToWorld(sx, sy)` / `screenToTile(sx, sy)` | экран → мир / клетка |

### 9.3 Выделение

| Метод | Назначение |
|-------|-----------|
| `rebuildBuffer()` | перерисовка буфера и слоя сетки; пересчёт контуров выделения |
| `pickTile(sx, sy)` | клетка под точкой (в режиме `adaptive` — через ячейку painter'а) |
| `selectAt(point)` | выделяет клетку и (если суша) весь регион |
| `clearSelection()` | снять выделение |
| `regionOutline(region)` | внешняя граница региона по клеткам (запасной вариант) |
| `regionShape(region)` | форма региона (скруглённый контур painter'а или по клеткам) |
| `pathFromLoops(loops)` | замкнутые ломаные → `Path2D` |
| `cellShape(tile)` | форма выделенной клетки (или `null` → скруглённый квадрат) |
| `roundedRectPath(...)` | путь скруглённого прямоугольника |
| `drawSelection()` | рисует выделение поверх карты (без перерисовки буфера) |

### 9.4 Вывод и ввод

| Метод | Назначение |
|-------|-----------|
| `resize()` | подгонка размера холста |
| `draw()` | фон → кусок `buffer` → слой сетки → выделение → объекты |
| `bindEvents()` | мышь (перетаскивание, клик), колесо (зум), клавиатура (стрелки/WASD, +/−, Esc) |
| `pointerToCanvas(e)` | координаты курсора относительно холста |
| `reportHover(e)` | сообщает `onHover` информацию о клетке |

Колбэки: `onHover`, `onSelect`, `onObjectClick`. Настройки: `tileSize`, `minZoom`, `maxZoom`,
`zoomStep`, `keyPanStep`, `backgroundColor`, `mood`, `selectionShape`, `selectionCorner`,
`outlineSmoothing`, `cellSmoothing`.

## 10. main.js — точка входа
