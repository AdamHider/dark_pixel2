# docs/ — справочные материалы (не код приложения)

Сюда вынесено то, что **не подключается** в `index.html` и не участвует в сборке:

- `MapGeneratorReference.js` — большой референс генератора, на который ссылаются
  `CODE_GUIDE.md` и `OPTIMIZATION.md` (имена секций). Не исполняется.
- `map-*.js`, `painter-*.js`, `map-renderer.js` — ранняя попытка разбить
  `map-generator.js` / `map-painter.js` на модули. **Не подключена** нигде: рабочие
  версии — это монолитные `map-generator.js` и `map-painter.js` в корне. Оставлена
  как источник идей для будущего разбиения.

Рабочий код и инструменты лежат в корне репозитория и в `tools/`.
